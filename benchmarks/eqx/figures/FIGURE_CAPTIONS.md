# ICTC-O2 HP 0.1.5 publication figures

Only completed 0.1.5 measured shapes are used. N counts independent tensor-product rows; m_max covers1–6. Figures use centred descriptive comparison titles and concise operation/range subtitles, sparse colourbar ticks and concise plotting labels. Coverage, numerical method and interpolation details are recorded here and in the data/geometry audits. Preview contains explicit PENDING cells where scanning is unfinished. Final figures require all240 shapes/480 metrics and60 reference families.

Throughput ratio is ICTC/EQX rows/s. Memory ratio is EQX/ICTC peak memory. Both use1x as neutral and>1x favours ICTC. Every relative heatmap cell and scale includes ×; no memory percentages are mixed with throughput ratios. For example,2.19x memory ratio means EQX uses2.19 times the ICTC footprint. Separate absolute-memory figures use GiB. Colour/height scales are shared across C/parity/N within each metric/operation. A dagger marks overlapping paired IQRs (descriptive, not a significance test). An asterisk marks isolated timing after joint-process OOM. A double dagger marks a small memory increase whose ratio rounds to1.00x; exact values remain in CSV/JSON. Hatched OOM cells are labelled EQX and have no finite comparison ratio. 3D OOM regions use white diagonally hatched frames with labels inside the projected missing region, with no assigned ratio. 2D parity headers are centred per panel. A 3D white frame covers an interpolation cell touching the failed measured corner, rather than declaring all adjoining measured points OOM. 3D axes are m_max, N and channel count C, with N/C at log2 spacing; colour alone represents ratios. Each vertical sheet is one measured N. Filled 3D surfaces use bilinear colour interpolation only within cells with four measured corners, without overshoot or filling missing/OOM cells. Dense bilinear vertices receive continuous Gouraud colour interpolation, including the C direction and joined boundary faces. Shared vertex ratios are audited for continuity. PDF/SVG use 450-dpi raster surface fills to avoid polygon stitching seams; text, axes, measured markers and OOM hatches remain vector. The lower 3D row uses peak allocated memory. A light-grey1x colour keeps neutral regions visible; the neutral threshold is unchanged. N ticks16/32/64/128 are in units of1,024 TP rows. Small outlined dots mark actual measured settings; interpolated colour points are not additional measurements. Geometry/corner audits are in surface_geometry.json.

The connected 3D view joins the C256, N131072 and m_max=6 boundary faces. Channel gradients on the two vertical faces connect the measured C levels. Interior values are shown in the companion N sheets and full heatmaps; the connected exterior does not expose every interior case. All source corners/masks are audited in connected_geometry.json.

All numerical gates cover every output/input-gradient row and every path weight at maximum N, FP32 gate1e-5. Full VJP includes both input gradients and all packed weights. Allocator memory includes inputs, parameters, outputs/adjoints, workspace and the precreated cotangent retained in forward-only measurement as well. NVML includes context/cache and samples may miss transients. PNG450dpi, editable SVG, embedded PDF fonts.
