# L1–L8 stability repair from the personal fork

This series starts from `a1dc6c9`, with operator sources corresponding to `5764f66`. It preserves the original loss, precision, numerical gates, active parameters and continuous optimizer/EMA/scheduler/RNG state. GPU work uses one A100 serially, with independent CPU-AMD audits.

`allocator-v7a` removes the local `coverage.py` import collision from the new control directory and uses `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True` on both backends. Native gradients that the original backward would clear before use are released before diagnostics. No training state is restored inside a trajectory.

With the old allocator policy, new job 120842 preserved an L8 second-mixed-diagnostic OOM even after old-gradient release. With expandable segments, native, native-repeat and candidate job 120845 captured all three steps. CPU-AMD audit 120846 passed L8 E/F, joint VJP, actual force-loss mixed derivatives, native updates and three-step comparisons under the original thresholds. This is an L8 three-step result, not a 20-step stability claim.

The L7 error was localized to one four-row angular tail layout. The earlier plan search stopped at 32 partitions and used an in-gate approximation. Probe 120853 isolated all observed angular differences to that tail. Search 120857 found a 54-partition single-chain FP32 plan with zero differences for both preserved actual mixed-derivative and training operand sets. Candidate `13c9328` changes only that plan and includes the plan JSON in installed packages. Targeted AMD audits 120867/120868 passed the L7 original three-step protocol and 72 tail/permutation/stride/seed regressions. Package audit 120865 verified all 6,576 installed plans.

Full fresh capture 120870 and independent AMD audits 120876/120877 passed all 144 operator configurations, 240 local derivative regressions, the original L4/M2 checkpoint anchor and all L1–L8 structural networks under the original E/F, joint VJP, actual mixed-derivative and continuous three-step gates. Some roles retain nonzero errors within those gates.

All L1–L8 structural networks also passed 20 continuous own-loss training steps and three fresh inference processes of ten calls each, using each backend's own updated raw weights. Independent per-order CPU-AMD audits passed all 162 comparison groups per order, including state/RNG continuity, complete gradients and native optimizer/EMA/scheduler updates.
